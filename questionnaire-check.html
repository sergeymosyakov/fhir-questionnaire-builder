What is Form Check?

Form Check tests what a questionnaire calculates (scores, severity bands, totals) without anyone filling it in by hand. It tries many combinations of answers and shows what each calculation gives. It runs in your browser: nothing is uploaded and the questionnaire is not changed.

Check a questionnaire
Drop a Questionnaire .json file. For every calculation you see the results it can give, the results it can never give (for example a severity band whose threshold was mistyped), the questions whose Show When rule is never met, and every answer combination that was tried (as a table, and as a CSV).
Save reference file
After a check, save the questionnaire together with all the answers that were tried and what the form calculated for them, as one file. It is a snapshot of “this is how the form should calculate today”.
Compare with a saved reference
When someone has edited the questionnaire, give the edited form and the reference file. The same answers are run through both versions, and you see which calculations changed (with the answers and “was → now”), which questions were removed or lost an answer option, and which formulas were edited.

Choose what to do above. Or open the builder: first open the questionnaire there (load a file or pick one from the library), then use Settings ▾ → Check my form…. Its report opens here.
