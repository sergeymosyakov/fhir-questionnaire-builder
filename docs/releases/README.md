# Release notes

`widget/<semver>.md` is the body of the GitHub Release `widget-v<semver>` of the QuestionnaireRenderer widget, written by hand for the people who embed it (no title line: the release has one). The release workflow refuses to run without the file for the version it is about to publish. How to write one: [release-widget skill](../../.github/skills/release-widget/SKILL.md).
